# Безопасность

**Один сервер — много независимых домов.** Данные принадлежат дому: календари, настройки, фоны, музыка и устройства. Участники одного дома видят его расписание и управляют экраном; соседние дома друг для друга невидимы. У владельца сервера есть административный доступ к хранилищу — подключайте календари только к серверу, оператору которого доверяете.

- Только HTTPS. Порт 3000 не выставлять в интернет.
- Telegram: подпись Mini App проверяется на каждом запросе; команды только в личных чатах.
- Членство в доме проверяется на каждом запросе. Чужой `X-Dino-Home-Id` даёт 403, а не чужие данные.
- У каждого телевизора и телефона свой токен; общих ключей нет. Приглашения одноразовые, действуют 10 минут.
- Первый телевизор дома подтверждает его владелец.
- Состояние каждого дома шифруется отдельно, с ID дома в качестве AAD.
- Пульт выключен по умолчанию: `TV_REMOTE_ENABLED=false`.
- Не доверяйте произвольному `X-Forwarded-For`: `TRUST_PROXY` по умолчанию пуст.
- Не публикуйте `.env`, `data/`, ключи SSH, подписи приложений и резервные копии.
- Один процесс backend: очереди и ограничения запросов хранятся в памяти.
- Шифрование хранилища не спасает при взломе VPS, на котором лежит ключ.
- `REGISTRATION_OPEN=true` делает вас оператором чужих персональных данных: [обязанности](https://github.com/dinosaur-tv/backend/blob/main/docs/HOSTED_SERVICE.md).

## Отзыв доступа

«Ещё → Отключить все устройства» отзывает устройства и приглашения этого дома и обесценивает незавершённые переходы OAuth (`POST /v1/miniapp/access/revoke`). Соседние дома не затрагиваются.

Владелец удаляет участника в «Ещё → Дом и участники»: вместе с ним отзываются его телефон, его приглашения и подключённый им календарь. «Удалить этот дом» стирает дом, его фоны и доступ всех его устройств.

Календарь отключается в приложении. Для отзыва разрешения у Google удалите приложение в настройках Google Account.

## Перед публикацией

Замените все ранее использованные/отправленные в чат ключи. Проверьте историю Git, снимки экрана, сборки и логи. Включите GitHub secret scanning и приватные сообщения об уязвимостях.

Уязвимости: Security → Advisories → Report a vulnerability. Если кнопки нет, запросите приватный контакт без описания уязвимости в публичной задаче.

Проверки кода и тесты не заменяют независимый аудит безопасности.
