# Участие в проекте

1. Опишите проблему и ожидаемое поведение.
2. Сделайте отдельный небольшой PR; добавьте тест на исправление.
3. Выполните проверки из README и `pre-commit run --all-files`.
4. Обновите инструкцию, если меняется установка или API.

Не добавляйте секреты, реальные события календаря и чужие изображения без лицензии. Общайтесь уважительно. Уязвимости сообщайте по [SECURITY.md](SECURITY.md).

Вклад в исходный код распространяется по MIT.
